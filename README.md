# Mobile View для MeshCentral

Плагин добавляет кнопку «Мобильный вид», адаптирующую панели удалённого рабочего стола и терминала для сенсорного экрана. Режим включается вручную и сохраняется в браузере. Соединения, права доступа и обработка касаний остаются штатными функциями MeshCentral.

В терминале кнопка «Клавиатура» открывает клавиатуру устройства при использовании xterm; если xterm недоступен, используется штатный диалог вставки текста. Доступность конкретных режимов зависит от версии MeshCentral и браузера. Для удобства рабочего стола можно повернуть устройство горизонтально и использовать встроенные настройки масштаба и ввода MeshCentral.

## Установка

В настройках MeshCentral включите поддержку плагинов. В панели администратора добавьте плагин по ссылке:

https://raw.githubusercontent.com/Sokol549/meshcentral-mobileview/master/config.json

Включите плагин и при необходимости перезапустите MeshCentral. Обновите страницу браузера. Для отключения режима нажмите кнопку повторно.

Совместимость интерфейса зависит от версии MeshCentral: плагин рассчитан на стандартный веб-интерфейс с элементами `p11` и `p12`.
